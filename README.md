# Reto 5 - QA Cloud-Native

## Automatización Inteligente con IA Generativa

Proyecto desarrollado para el Reto Práctico del Módulo 5 del Diplomado de Automatización de Pruebas de Software.

## Objetivo

Implementar una estrategia integral de aseguramiento de calidad para una aplicación de comercio electrónico, combinando automatización funcional, datos sintéticos, integración continua, ejecución en la nube, contenedores y pruebas de contratos.

## Tecnologías

- JavaScript y Node.js
- Faker
- Python y pytest
- Playwright
- BDD con pytest-bdd
- Patrón Screenplay
- IA Generativa y MCP
- Azure DevOps y Azure Pipelines
- Docker
- Pact
- Git y GitHub

## Estructura del proyecto

- app-tienda/: aplicación bajo prueba.
- datos/: generación de datos sintéticos.
- e2e/: framework de automatización.
- pipeline/: CI/CD y Quality Gates.
- pact/: pruebas de contratos API.
- docs/: documentación y evidencias.

## Fases del reto

1. Generación reproducible de datos.
2. Pipeline CI/CD con Quality Gates.
3. Automatización BDD con IA Generativa.
4. Ejecución de pruebas en la nube.
5. Contenedores y pruebas de contratos.
6. Métricas DORA y estrategia de calidad.
